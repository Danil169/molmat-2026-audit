Упражнение II.8 — адсорбция на поверхности
-------------------------------------------
Папка: ``materials-modeling/8_Adsorption``.

**Водород на графене C8 — выполнено полностью:**

.. list-table::
   :header-rows: 1

   * - Система
     - Энергия, eV
     - Совпадение с референсом
   * - Релаксация H@C8
     - −1319.069282
     - −1319.069236 (✓)
   * - Атом H (спин-поляризованный)
     - −12.559509
     - −12.559508 (✓)
   * - Поверхность C8
     - −1303.645873
     - −1303.645828 (✓)

Энергия адсорбции: ``E = E(C8) + E(H) − E(H@C8) = 2.8639 eV`` —
совпадает с референсным значением курса. Полученное значение выше
литературных 0.7–1.9 eV для одиночного H на графене, что объясняется
малым размером модели (1 H на 8 атомов — высокое покрытие) и вкладом
дисперсионной поправки D3.

**Ртуть на графене C18 — выполнено:**

.. list-table::
   :header-rows: 1

   * - Система
     - Энергия, eV
     - Совпадение с референсом
   * - Релаксация Hg@C18 (позиция on-top)
     - −7481.346431
     - −7481.346431 (✓)
   * - Сляб C18
     - −2947.320598
     - −2947.320598 (✓)
   * - Атом Hg
     - −4533.787985
     - −4533.787985 (✓)

Энергия адсорбции: ``E = E(Hg@C18) − E(C18) − E(Hg) = −0.2378 eV`` —
совпадает с референсом курса. Значение в 12 раз меньше энергии связи
водорода (2.86 eV): ртуть удерживается на графене только дисперсионными
(ван-дер-ваальсовыми) силами — это физисорбция, в отличие от
хемосорбции водорода. Равновесная высота атома ртути над плоскостью
≈ 3.41 Å — характерное ван-дер-ваальсово расстояние; графеновый лист при
релаксации практически не деформируется. Результат согласуется с
экспериментальным диапазоном для ртути на графите/графене
(−0.18…−0.25 eV).

*Челлендж выполнен:* энергии адсорбции на трёх позициях:

.. list-table::
   :header-rows: 1

   * - Позиция
     - E(Hg@C18), eV
     - E_ads, eV
   * - top (над углеродом)
     - −7481.346431
     - −0.2378
   * - bridge (над серединой связи)
     - −7481.638000
     - −0.5294
   * - hollow (над центром шестиугольника)
     - −7481.774037
     - −0.6655

Позиция **hollow оказалась выгоднее на 0.43 eV**, чем top. Это нетипично
для физисорбции, но объяснимо малым размером модели (18 атомов):
периодические границы и ограниченное число атомов создают искусственное
усиление притяжения в центре кольца, где электронная плотность π-системы
высока. На больших поверхностях разница между позициями обычно < 0.1 eV.
Для сравнения: водород образует ковалентную связь и «привязан» к конкретному
атому углерода, тогда как ртуть «чувствует» электронную структуру всего
фрагмента.
